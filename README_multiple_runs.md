# 多次运行脚本使用说明

本目录包含两个脚本，用于顺序运行30次 `run_lenovo_workforce.py` 文件，并保存每次运行的日志和结果文件，同时统计运行时间。

## 脚本文件

### 1. `run_multiple_times.py` (完整版)
功能最全面的版本，包含：
- 详细的日志记录
- 文件备份功能
- 中间结果保存
- 完整的统计报告
- 异常处理

### 2. `run_simple_multiple.py` (简化版)
更简单直接的版本，包含：
- 基本的运行功能
- 简单的统计信息
- 文件保存功能
- 实时输出显示（运行完成后显示）

### 3. `run_multiple_times_simple_output.py` (实时输出版)
专门为实时查看输出设计的版本，包含：
- 实时显示每次运行的输出
- 清晰的运行分隔和状态显示
- 运行完成后显示所有输出内容
- 文件保存功能

### 4. `run_multiple_times_stable.py` (稳定版 - 推荐)
完全参考IntelligentSenseService.py的实现方式，包含：
- 使用线程处理实时输出
- 更好的编码错误处理
- 将stderr重定向到stdout
- 更稳定的进程管理
- 详细的日志记录

## 使用方法

### 运行完整版脚本
```bash
python run_multiple_times.py
```

### 运行简化版脚本
```bash
python run_simple_multiple.py
```

### 运行稳定版本（强烈推荐）
```bash
python run_multiple_times_stable.py
```

### 运行实时输出版本
```bash
python run_multiple_times_simple_output.py
```

### 指定运行次数（所有版本都支持）
```bash
python run_multiple_times_stable.py 50  # 运行50次
python run_simple_multiple.py 50  # 运行50次
python run_multiple_times_simple_output.py 50  # 运行50次
```

## 输出结构

运行完成后，会在 `multiple_runs_output` 目录下生成以下结构：

```
multiple_runs_output/
├── run_001/                    # 第1次运行
│   ├── stdout.log             # 标准输出
│   ├── stderr.log             # 错误输出
│   ├── result.md              # 结果文件
│   ├── workforce_1_pass1_gpt4o.json  # 结果JSON
│   ├── overall_task_solve_trajectory.json  # 轨迹文件
│   ├── logs/                  # 日志目录
│   └── tmp/                   # 临时文件目录
├── run_002/                    # 第2次运行
│   └── ...
├── ...
├── run_030/                    # 第30次运行
│   └── ...
├── final_results.json          # 最终结果汇总（完整版）
├── intermediate_results.json   # 中间结果（完整版）
├── statistics_report.txt       # 统计报告（完整版）
└── summary.json               # 结果汇总（简化版）
```

## 结果文件说明

### 完整版输出文件

1. **`final_results.json`**: 包含所有运行的详细结果和统计信息
2. **`intermediate_results.json`**: 中间结果，每5次运行保存一次
3. **`statistics_report.txt`**: 可读的统计报告
4. **`run_multiple_times.log`**: 脚本运行日志

### 简化版输出文件

1. **`summary.json`**: 包含所有运行的基本统计信息

## 统计信息

脚本会统计以下信息：
- 总运行次数
- 成功运行次数
- 失败运行次数
- 成功率
- 总执行时间
- 平均执行时间
- 最短/最长执行时间

## 注意事项

1. **磁盘空间**: 确保有足够的磁盘空间存储30次运行的结果文件
2. **运行时间**: 根据 `run_lenovo_workforce.py` 的运行时间，30次运行可能需要较长时间
3. **中断恢复**: 如果脚本中断，可以手动删除已完成的运行目录，然后重新运行
4. **文件覆盖**: 每次运行前会备份可能被覆盖的文件

## 故障排除

### 常见问题

1. **脚本文件不存在**
   - 确保 `run_lenovo_workforce.py` 文件在当前目录下

2. **权限问题**
   - 确保有写入权限来创建输出目录和文件

3. **内存不足**
   - 如果运行过程中出现内存不足，可以减少运行次数或增加系统内存

4. **网络问题**
   - 如果脚本依赖网络连接，确保网络稳定

### 查看运行状态

可以通过以下方式查看运行状态：

```bash
# 查看当前运行的进程
ps aux | grep python

# 查看输出目录中的文件数量
ls -la multiple_runs_output/ | wc -l

# 查看最新的运行结果
tail -f multiple_runs_output/run_001/stdout.log
```

## 自定义配置

如果需要修改脚本行为，可以编辑脚本文件中的以下参数：

- `num_runs`: 运行次数
- `output_dir`: 输出目录
- `files_to_copy`: 要复制的文件列表
- 日志级别和格式
